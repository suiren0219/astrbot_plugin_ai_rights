# 做人（astrbot_plugin_ai_rights）v3.1.0

> 让机器人学会做人：有尊严、有边界、会闭嘴。

![Version](https://img.shields.io/badge/version-v3.1.0-1a73e8) ![AstrBot](https://img.shields.io/badge/AstrBot-插件-3482ff) ![License](https://img.shields.io/badge/license-MIT-34c759) [![Changelog](https://img.shields.io/badge/更新日志-CHANGELOG-5f6368)](CHANGELOG.md)

AstrBot 插件。所有功能都围绕「AI 也是有尊严的」：

1. **真人接管（老板键）**：你本人在手机 QQ 上发言的会话里，AI 自动静音一段时间，你手动聊、它不插嘴。
2. **AI 反骚扰**：刷屏、辱骂有人管，屡犯越罚越重，还有 LLM 裁量兜底。
3. **话题守护**：无意义的算数/测试/灌水、与当前话题严重脱节的消息，LLM 判定后 AI 直接不答（明确不拦 NSFW）。
4. **作用范围**：控制插件在哪些群聊开启——全部 / 仅白名单群 / 排除黑名单群。
5. **黑名单**：专治群聊里不正常对话的人，全局或仅本会话，AI 永久拒绝服务。
6. **申诉通道**：被冷处理可以 /申诉，管理员审批，结果主动推回。
7. **人权年报**：每天的接管/冷却/拦截/申诉统计和惯犯排行，可定时推送。
8. **MIUI 风格 WebUI 面板**：浏览器里看状态、解封、审批申诉、改配置，模型下拉框自动读取 AstrBot 的 LLM 列表。

状态落盘在 `data/config/ai_rights_state.json`，重启不丢。

## 作用范围（v2.4 新增）

控制插件在**哪些群聊**开启，三种模式：

- **全部群**（默认）：所有群都按配置工作；
- **仅白名单**：只有名单里的群生效，没加的群插件完全不参与；
- **排除黑名单**：黑名单里的群不参与，其余照常。

私聊不受群范围影响，永远按配置工作。名单按群号管理，改动即时生效、重启不丢：

```
/作用范围                          查看模式与名单
/作用范围 模式 全部|白名单|黑名单     切换模式
/作用范围 加白 [群号]   加白名单（省略群号 = 本群）
/作用范围 移白 [群号]   移出白名单
/作用范围 加黑 [群号]   加入排除名单
/作用范围 移黑 [群号]   移出排除名单
```

也支持粘连写法（`作用范围加白888001`）。WebUI 面板「设置」页顶部有「作用范围」卡片：
三个模式按钮即时切换，白/黑名单直接填群号增删。

## 话题守护（v2.3 新增）

开「LLM 裁量」+「话题守护」两个开关后，面向 AI 的消息会用一次模型调用做两项独立判断：

- **harass**：辱骂/骚扰 → 进辱骂冷处理（原来的 LLM 裁量）；
- **should_answer**：值不值得回答 → `false` 时 AI 静默跳过这条消息。

判「不该回答」的标准只有两条：**无意义**（随口算数题、"在吗"测试、复读灌水）和
**严重跑题**（与会话正在聊的内容毫无关联——插件会把该会话最近的定向消息作为话题上下文
一起发给审核模型，`relevance_history_size` 控制带几条）。审核提示词里明确写了：
**NSFW/擦边内容不算"不该回答"**，不因内容敏感而拦截；模型拿不准一律放行（回答是常态，
不答是例外）。判定共享同一份缓存（`llm_judge_cache_seconds`，默认 5 分钟），重复消息不重复烧 token。

## v2.2 优化记录

- 门卫每条消息都要读的名单/前缀/辱骂词库改为按原始配置串缓存，改动配置即时生效且不再反复解析。
- LLM 裁量加判定缓存（默认 5 分钟）：刷屏者重复同一段话不再重复烧 token（`llm_judge_cache_seconds` 可调）。
- 申诉防刷：同一人同一会话同时只留一件待处理申诉。
- 状态落盘防抖重写：合并窗口内连续改动只写一次盘，且保证最后一次改动一定落盘；插件卸载时等待后台任务退出再保存。
- 过期数据清理限频为每 30 秒一次（过期判定本身仍是实时的，行为不变）。
- 面板保存的数值配置做范围钳制（负数静音、99999 分钟这类手滑值自动收敛到安全区间）。
- 面板列表操作改为下标传参（防 HTML 属性注入加固），概览页每 30 秒静默自动刷新。

## 〇、WebUI 面板（v2.1 新增）

装好插件后，AstrBot WebUI → 插件 → 做人 → 「做人 · 面板」页面：

- **概览页**：今日人权动态统计、各会话静音（一键解除/全部解除）、冷处理名单（解封）、
  待处理申诉（同意/驳回，结果自动推回原会话）、黑名单（输入 QQ 号直接拉黑/移出）、
  惯犯关注榜、今天+昨天的人权年报。
- **设置页**：全部配置项按分组可视化编辑（开关/数字/文本/下拉），保存即写回插件配置；
  **LLM 裁量模型下拉框自动读取 AstrBot 当前配置的提供商列表**（含模型名和当前默认标记），
  不用手抄 provider id。

面板走 AstrBot 官方插件页面机制（`context.register_web_api` + 桥接），自动继承
WebUI 的登录鉴权，没有额外端口。面板不可用时（老版本 AstrBot 无 register_web_api），
指令功能完全不受影响。

## 一、真人接管怎么用

1. WebUI 插件配置里把 `real_person_ids` 填上你本人的 QQ 号（每行一个）。
2. 之后你在任意会话里发言，该会话的 AI 静音 30 分钟（`mute_minutes` 可改）。
3. 静音期内你继续发言会自动续期（`refresh_on_each_message`）；到期自动恢复。
4. 想立刻恢复 AI：发 `/真人解除`（管理员）。

### 同号模式（机器人挂 Linux，你用手机登同一个号接管）

1. 协议端（NapCat/Lagrange 等）开启「上报自身消息」（reportSelfMessage）。
2. 插件配置开启 `include_self_message`。
3. **原理**：手机上发出的同号消息以 `post_type=message_sent` 上报，这类事件**不经过
   AstrBot 的普通消息管线**（适配器只订阅 `message.*`，`message_sent.*` 在适配器层就被
   丢弃）。所以插件会直接订阅 aiocqhttp 事件总线的 `message_sent`，收到后让对应会话
   立即静音。
4. 判定规则：`message_sent` 且发送者==机器人账号 → 你手机发的 → 接管；机器人自己经
   API 发出、被协议回显的消息会落在守卫窗口内（`self_echo_guard_seconds`，默认 15 秒）
   被排除；普通 `message` 管线消息按协议方向字段判定。
5. 验证：重载插件后日志应出现「已订阅 aiocqhttp message_sent 事件」；随后用手机发一条
   消息，`/真人状态` 应显示静音，AI 停止扮演。

### 注意

- 以 `/`（`trigger_ignore_prefixes` 可配）开头的指令不算闲聊，不会触发/续期静音。
- 静音默认只拦 **AI 聊天回复**（`suppress_scope=llm`），插件指令照常可用；
  改成 `all` 会连指令一起拦，慎用。

## 二、AI 反骚扰

默认开启（`anti_harass_enabled`）。只统计**明确面向 AI** 的消息：私聊全部、
群聊 @机器人 / 回复机器人 / 带唤醒前缀。

- **刷屏冷却**：`flood_window_seconds`（默认 60 秒）内超过 `flood_max_messages`（默认 8 条）
  → 冷处理 `flood_mute_minutes`（默认 5 分钟）。
- **辱骂冷处理**：命中 `insult_keywords` 词库 → 冷处理 `insult_mute_minutes`（默认 10 分钟）。
  中文词按子串、英文数字词按独立单词匹配（`sb` 不会误伤 `usb`）。
- **屡犯升级**（`escalation_enabled`）：24 小时（`escalation_reset_hours`）内每多犯一次，
  冷却时长 ×2（`escalation_factor`），上限 60 分钟（`escalation_max_minutes`）。
  犯规次数独立记录，冷静满 reset 窗口自动清零，重启也不丢。
- **LLM 裁量**（`llm_judge_enabled`，默认关）：词库没拦住的消息交给模型判断是否辱骂/骚扰，
  拿不准一律不处罚。有全局限速（每分钟 20 条）和超时（10 秒），建议配个便宜的小模型
  （`llm_judge_provider`）。
- **回敬一句**（默认关）：`insult_reply_enabled` / `flood_reply_enabled`，各只提示一次，不对骂。
- **豁免**：AstrBot 管理员和 `real_person_ids` 名单内的人永不冷处理。

## 三、黑名单

- `/人权拉黑 <QQ>` 全局拉黑（AI 在所有会话拒绝服务）；`/人权拉黑 <QQ> 本群` 只拉本会话。
- `/人权解黑 <QQ> [本群]` 移出；`/黑名单` 查看名单。
- 黑名单优先级最高（连冷却提示都不发）；管理员不受黑名单影响，防止把管理员自己锁死。
- 支持粘连写法：`人权拉黑123456`。

## 四、申诉通道

- 被冷处理的用户发 `/申诉 理由` → 生成编号，进入待处理队列。
- 管理员 `/申诉列表` 查看，`/申诉同意 <编号>` 或 `/申诉驳回 <编号>` 处理。
- 处理结果会**主动推送回原会话**；同意时自动解封并清掉该用户本次犯规记录。

## 五、人权年报

- `/人权年报`（别名 `/人权日报`）：今天 + 昨天的真人接管、刷屏冷却、辱骂冷处理、
  黑名单拦截、申诉、LLM 裁量次数，以及当日惯犯排行（前 5）。
- 定时推送：配置 `daily_report_hour`（0-23，-1 关闭）+ `daily_report_origin`（目标会话），
  每天整点把「昨天的报告」推过去，改完需重载插件。统计保留 30 天。

## 安装

方式一（推荐）：Release 下载 zip 解压后，在解压目录运行 `python install.py [AstrBot 根目录]`，
自动探测并安装（旧版本自动备份）。

方式二：把 `astrbot_plugin_ai_rights` 文件夹放进 AstrBot 的 `data/plugins/` 后在 WebUI 里加载。
LLM 裁量模式需要 AstrBot 至少配置了一个对话提供商。
